# 写真フォルダ作成（PhotoFolderMaker）

写真ファイルをドラッグ＆ドロップするだけで、**その写真をアイコンに合成した新規フォルダ**を作る macOS 用のドロップレットアプリです。

写真の中身がアイコンのまま見えるので、Finder 上で「どのフォルダに何が入っているか」を開かずに判別できます。

- 言語: AppleScript（AppleScriptObjC / Foundation + AppKit）
- 対応 OS: macOS（Apple Silicon / Intel 両対応のユニバーサルバイナリ）
- 追加インストール: 不要（標準の `osacompile` だけでビルドできます）

---

## できること

写真ファイル `海_2026.jpg` をアプリのアイコンにドロップすると、

1. `海_2026_フォルダ` という名前のフォルダが作られ、
2. そのフォルダのアイコンが「標準のフォルダアイコン＋`海_2026.jpg` を中央に合成した画像」になります。

複数のファイルをまとめてドロップすれば、ファイルの数だけフォルダがまとめて作られます。

### アイコン合成の仕様

| 項目 | 値 |
|---|---|
| キャンバスサイズ | 512 × 512 px |
| 写真の最大表示領域 | 384 px（縦横比は維持） |
| 配置 | 水平方向は中央、垂直方向は中央から 15 px 下 |
| 下地 | macOS 標準のフォルダアイコン（`NSWorkspace` から取得） |

フォルダ名は、元のファイル名から拡張子を取り除いたものに `_フォルダ` を付けたものになります。

## 2 つのバージョン

本アプリには、作成先の決め方が違う 2 つのバージョンがあります。

| アプリ名 | 作成先 |
|---|---|
| **写真フォルダ作成.app**（標準） | ドロップするたびに保存先を選ぶダイアログが出ます。1 回のドロップにつき 1 回だけ聞かれ、複数ファイルをまとめてドロップした場合は全部が同じ場所に作られます。 |
| **写真フォルダ作成_デスクトップ固定.app** | 保存先を聞かずに、常にデスクトップ直下に作ります。 |

迷ったら標準版を使ってください。毎回同じ場所（デスクトップ）に作るのが決まっている場合は、確認ダイアログの出ないデスクトップ固定版が速いです。

## インストールと使い方

### 1. ダウンロード

[Releases](../../releases) ページから `PhotoFolderMaker-<バージョン>-macOS.zip` をダウンロードして展開します。

### 2. 配置

展開した `写真フォルダ作成.app` を「アプリケーション」フォルダなど好きな場所に置きます。

### 3. 初回起動時の注意（重要）

このアプリは Apple Developer ID による署名・公証（notarization）を受けていません。そのため、**ダウンロード直後は macOS の Gatekeeper にブロックされ、次のような警告が出ます。**

> 「写真フォルダ作成」は壊れているため開けません。ゴミ箱に入れる必要があります。

アプリが壊れているわけではありません。「インターネットからダウンロードされた未署名アプリ」に付く隔離属性（quarantine）が原因です。解除するには、ターミナルで次のコマンドを実行してください（パスはアプリを置いた場所に合わせてください）。

```bash
xattr -dr com.apple.quarantine /Applications/写真フォルダ作成.app
```

実行後、通常どおりダブルクリックで起動できます。

<details>
<summary>それでも開けない場合</summary>

- アプリを右クリック（control + クリック）して「**開く**」を選び、確認ダイアログで「開く」を押す
- 「システム設定」→「プライバシーとセキュリティ」を開き、下の方に出る「"写真フォルダ作成" は開発元を確認できないため……」の横の「**このまま開く**」を押す

後述の「ソースからビルドする」手順で自分のマシン上でビルドした場合は、そもそも隔離属性が付かないため、この操作は不要です。

</details>

### 4. 使う

写真ファイルを **アプリのアイコンにドラッグ＆ドロップ** してください。Dock に登録しておくと便利です。

アプリを普通にダブルクリックで起動した場合は、使い方を説明するダイアログが表示されるだけで、フォルダは作られません。

## ソースからビルドする

```bash
git clone https://github.com/Geology-cat/photo-folder-icon-maker.git
cd photo-folder-icon-maker
./scripts/build.sh
```

`dist/` に 2 つのアプリが生成されます。配布用の zip もあわせて作る場合は次のようにします。

```bash
./scripts/build.sh --zip
```

バージョン番号は環境変数で指定できます。

```bash
VERSION=1.1.0 ./scripts/build.sh --zip
```

ビルドスクリプトは `osacompile` でアプリを生成したあと、ad-hoc 署名（`codesign --sign -`）を付与します。これは Apple Developer ID による署名ではないため、配布時の Gatekeeper 警告は解消されません。

## リポジトリ構成

```
.
├── src/
│   ├── PhotoFolderMaker.applescript          # 標準版（保存先を選択）
│   └── PhotoFolderMaker-Desktop.applescript  # デスクトップ固定版
├── scripts/
│   └── build.sh                              # ビルドスクリプト
├── LICENSE
└── README.md
```

ビルド済みのアプリバンドル（`.app`）は Git では管理していません。`.app` はディレクトリ構造と署名を持つため Git で正しく扱えないためです。配布は Releases の zip で行います。

## 既知の制限・注意点

- **画像以外のファイルを受け付けてしまいます。** アプリは拡張子を判定していないため、テキストファイルなどをドロップすると、アイコンのない空のフォルダだけが作られます（エラーは出ません）。
- **同名のフォルダがあると再利用され、アイコンが上書きされます。** 内部で `mkdir -p` を使っているため、既存フォルダがあっても新しく作り直さず、そのフォルダのアイコンだけが差し替わります。中のファイルが消えることはありませんが、警告も出ません。
- **アイコンの設定に失敗しても通知されません。** 画像として読み込めないファイルをドロップした場合、フォルダだけが残ります。
- **未署名・未公証です。** 上記「初回起動時の注意」を参照してください。
- 標準版をダブルクリック起動したときの説明ダイアログの文言が「デスクトップに作成します」のままになっています。実際の動作は保存先の選択です（表示上の問題のみで、動作には影響しません）。
